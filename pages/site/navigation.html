Navigation

The header menu is built in the Theme editor (Online Store › Themes › Customize) › Header. Each menu tab is a Tab Navigation block with two columns.

Add a tab

  1. Go to Theme editor › Header and click Add block › Tab Navigation.
  2. Enter a Title. Each tab needs a different title.
  3. Inside the tab, add Navigation Content (60%). This is the left column.
  4. Inside the tab, add Featured Content (40%). This is the right column.
  5. Add blocks to each column (see below) and click Save.

To make a tab a plain link with no dropdown, add no columns and fill in its Link.

Left column: Navigation Content (60%)

Blocks you can add to the left column. Click a card for tips.

Menu

Links from a Shopify menu, or a single link with its own blocks.

Menu Button

One button with a label and a link.

Banner

Image card with a title, subtitle and link.

Featured Products

1 to 8 products from a collection.

Product Cards

Products from a collection, as a slider or grid.

Image Cards

Two images side by side, each with a caption.

Health Goals Grid

Grid of health goals. You can also add it as a menu link: /type/health_goal_icons.

Blockquote

A quote with its author.

Right column: Featured Content (40%)

Blocks you can add to the right column. Click a card for tips.

Articles

Up to 5 Journal articles.

Banner

Image card with a title, subtitle and link.

Expert Team

Photos and names of our experts.

Add menu links

Links go in a Menu block. Build them with blocks, or use a Shopify menu.

Option 1: build links with blocks

  1. In the tab, add a Menu block. Fill in Single item (the link name) and leave Menu empty.
  2. For a plain link, fill in Link.
  3. For a link that opens its own panel, add blocks inside it, such as Menu, Banner, Product Cards or Articles.

Option 2: use a Shopify menu

  1. In the tab, add a Menu block and choose a menu in Menu.
  2. Edit the links in Shopify admin › Content › Menus.

Change how a link looks

Name the link in Shopify admin › Content › Menus like this:

Link nameShows as
Title - CollagenA heading, "Collagen". Add its links underneath it as child links.
Button - Shop allA green button, "Shop all". You can also use a Menu Button block.
Includes (v) or (New)A vegan badge or a "New" label.

Keep one space on each side of the dash.

List entries automatically (for example, all Science pages)

  1. In Shopify admin › Content › Menus, add a link with the URL /type/ followed by the entry type, for example /type/science or /type/health_goal_icons.
  2. The menu now lists every entry of that type, with its menu image. Entries with no menu image are skipped.
Change the order
  • Science: Shop metafields › Science. Reorder the entries there.
  • Other entry types: show in Shopify's default order.
  • Health goals: for a set order, use the Health Goals Grid block, which follows Shop metafields › Health goals.

Change the menu for one market

Change a setting or block for one market

  1. In the Theme editor, use the selector at the top to switch to the market, for example Germany.
  2. Edit the Header blocks and click Save. Only that market changes.

Use different menu links for one market

  1. In Shopify admin › Content › Menus, duplicate the menu. Add the market name to the end of its handle, for example v2-nav-shop becomes v2-nav-shop-germany.
  2. Edit the links and save. That market now uses this menu instead of the default one.
Check which market you're editing If no market is selected, your changes apply to every market.
