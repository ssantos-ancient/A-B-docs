Writing a new article

There are two kinds of Journal article. A default article is written in the blog post editor in Shopify admin › Content › Blog posts. A custom article is built with sections in the Theme editor (Online Store › Themes › Customize).

Write the article

  1. Go to Shopify admin › Content › Blog posts and click Create blog post.
  2. Write the text in Content.
  3. Use Heading 2 for section titles.
  4. Use Blockquote for quotes.

All the metafields below are at the bottom of the same post, under Metafields.

Add a cover image

  1. Add the cover in Image, about 2560 × 1013px. See Image sizes.
  2. If it looks badly cropped, add the image in Metafields › Article cover instead.
  3. In the metafield, set the focal point to fix the framing.

One cover is used for both desktop and mobile. On mobile, only the centre square shows.

Choose an author

  1. Go to Metafields › Author and choose an author.
  2. If they're not in the list, create them in Shopify admin › Content › Metaobjects › Author (name, photo, job title, bio, link), then select them.
  3. If there's no named author, choose Ancient + Brave.

Add a short intro

Fill in Metafields › Short intro. It shows below the title.

Add "In this article" links

  1. In Metafields › In this article, add each topic as a list item.
  2. Type each topic exactly as the matching heading in the content, character for character, or the link won't work.

Each topic becomes a link that jumps to that part of the article. You can copy and share these links.

Add "At a glance" points

  1. In Metafields › At a glance, add each point as a list item.
  2. The points show below "In this article".
Capitals are removed Only the first letter of each point stays capitalised, so "DNA" becomes "Dna". Reword points to avoid acronyms.

Publish the article

  1. Add at least one tag, so the article can be filtered. See Articles by tag.
  2. Set Theme template to Default blog post.
  3. Set Blog to Journal.
  4. Set visibility to Visible and click Save.

Optional: add products in Metafields › Featured products to show a product slider after the article.

Create a custom article

Use this for designed, long-form stories.

  1. Create the post in Shopify admin › Content › Blog posts as usual, and fill in the metafields and tags. Leave Content empty.
  2. Set Blog to Custom blog for now, so it doesn't show in the Journal yet.
  3. In the Theme editor, create a new blog post template based on custom-blog-post.
  4. Back in the post, set Theme template to your new template and set it to Visible.
  5. In the Theme editor, open your template and choose the article in Select article.
One template per article Every custom article needs its own template. Never reuse another article's template. "At a glance" doesn't show on custom articles.

Build and publish a custom article

  1. In the Theme editor, open your template and build the article with the blocks below.
  2. When it's ready, go back to the post in Shopify admin › Content › Blog posts and set Blog to Journal. It now shows in the Journal.

Blocks you can use

BlockUse it for
TextBody copy.
Builder 50 / 50Image and text side by side.

Related products sliderProducts inside the article.

Builder GridAn image grid with captions.
