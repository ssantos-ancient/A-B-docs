Subscriptions

Change the Subscribe & Save box on the product page (PDP). Most of it is set on each product in Shopify admin › Products › [product] › Metafields.

Choose the "How subscriptions work" content

The How subscriptions work link in the subscription box opens a side panel that shows the free gifts subscribers get.

  1. Go to Shopify admin › Products › [product] › Metafields › Subscription gifts.
  2. Select an existing entry (see the table below) and click Save.
  3. Need different gifts? Create a new entry in Shopify admin › Content › Metaobjects › Subscription gifts, then select it.
ProductEntry to select
PowderSubscription - Default
CapsulesSubscription - Pill Case
Always select it on the product If nothing is selected on the product, the panel shows whichever entry Shopify lists first.

Change the subscription message

The bullets under Subscribe & Save come from the first of these that is filled in:

  1. Shopify admin › Products › [product] › Metafields › ATC subscription info (an entry you select).
  2. Shopify admin › Products › [product] › Metafields › Subscription widget (a simple list).
  3. Theme editor › Theme settings › Add to cart area › Default Subscription Offer, which applies to all products.

To change it for one product:

  1. Go to Shopify admin › Products › [product] › Metafields › ATC subscription info.
  2. Select an existing entry, or create a new one in Shopify admin › Content › Metaobjects › ATC subscription info and select it. (ATC means add to cart.)
  3. Click Save.
Add an icon to a free gift Start the item with a number: 01 - Ritual Scoop. Numbers 01 to 05 each show a different icon (scoop, pill case, jar, tin, box). Keep one space on each side of the dash.

To change the one-time purchase box, do the same, but select the entry in Metafields › OTP purchase info (OTP means one-time purchase).

Change the purchase options

Turn these on in Shopify admin › Products › [product] › Metafields:

MetafieldWhat it does
One time purchase firstShows one-time purchase above subscription.
One time purchase preselectedSelects one-time purchase when the page opens.
ATC one time purchase featuredHighlights the one-time purchase option.
Hide subscriptionOffers one-time purchase only.
One time discount percentageAdds a "% Off" pill to the one-time option, for example "10% Off".

Show the green "Subscribe and save" banner

  1. Go to Theme editor › Theme settings › Add to cart area and turn on Highlight subscription option on ATC. It's currently off.
  2. To change the banner text for one product, fill in Shopify admin › Products › [product] › Metafields › PDP custom subscription box title.
  3. To add a pill, fill in Highlight subscription percentage in the same place, for example "30% Off".

These two product fields don't show on the site while the theme setting is off.
