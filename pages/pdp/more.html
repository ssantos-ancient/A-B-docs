More product options

Other product page features. Unless a step says otherwise, set them in Shopify admin › Products › [product] › Metafields. Some also need a setting in the Theme editor (Online Store › Themes › Customize).

Set up a pre-order

  1. In Shopify admin › Products › [product] › Metafields, turn on Preorder.
  2. In the same product, under Inventory, tick Continue selling when out of stock. Click Save.

The button now says "Preorder". The shipping date line is the same for all products. To change it, go to Shopify admin › Online Store › Themes, click … next to Customize, choose Edit default theme content and search for "preorder".

Show a product as sold out

  1. Turn on Fake out of stock. The button changes to "Sold out". Real stock doesn't change.
  2. Optional: add a Back in stock form ID from Klaviyo, so shoppers can sign up to hear when it's back.
  3. Optional: choose a Back in stock related product to recommend instead.

Show the price per serving

  1. Fill in Servings (for example "30 servings") and Number of servings (for example 30).
  2. In Theme editor, open a product page, click Product pages v2 and turn on Show Price per serving.

Change the price shown

Fill in both Overwrite price and Overwrite compare price. This only changes the price shown on the site. The cart still charges the real price.

Each section shows when its metafield is filled in and its setting is turned on in Theme editor › Product pages v2.

Lifecycle analysis works the other way round. Go to Shopify admin › Content › Metaobjects › Product lifecycle analysis, add the product to an entry, then turn on Show Lifecycle Analysis in Product pages v2.

Add text under the product title

  • Product form: a small line under the title, for example "Powder".
  • Breadcrumb collection: choose a collection to show a breadcrumb (the "back to" link above the title). With no collection, no breadcrumb shows.

Hide the menu for a landing page

Turn on Minimal header to hide the menu and announcement bar, leaving only the logo and cart. Useful for ad landing pages.

Set the product type

Set this in Shopify admin › Products › [product] › Product organization › Type (not a metafield).

  • Promo: no add to cart button. Instead, a button links to the same product without "-promo" in the web address. The product's handle (the end of its web address) must end in -promo.
  • Wholesale: no add to cart button.

Edit the side panel pages

These side panels show on every product page. They're normal pages, so edit them in Shopify admin › Online Store › Pages:

  • Delivery: page shipping
  • 30-day guarantee: page guarantee
  • Gift subscriptions: page gift-subscriptions-information
