Sibling products

Siblings are versions of the same product, such as a tub and sachets. They show as tiles above the add to cart box on the product page, so shoppers can switch between them. You set them in Shopify admin › Products › [product] › Metafields.

Link the sibling products

  1. Go to Shopify admin › Products › [first product] › Metafields › Siblings.
  2. Add every product in the group, including this one, in the order you want the tiles to show. Click Save.
  3. Repeat on every other product in the group, with the same list in the same order.
Use the same list on every product If one product has a different list, the tiles change as shoppers switch. Keep to 2 or 3 siblings, or the tile images are hidden.

Add a pill to a tile

A small label on top of a tile, for example "Best value".

  1. Go to Shopify admin › Products › [product that needs the pill] › Metafields › Sibling tag.
  2. Type the label and click Save.
