PLP banners

Banners that sit inside the product grid on a product listing page (PLP), also called a collection page. A Single Card takes one product space. A Double Card takes two, and a full row on mobile. You add them in the Theme editor (Online Store › Themes › Customize).

Add a banner to a collection

  1. In Shopify admin › Products › Collections › [collection], check the Theme template. To show banners on this collection only, create a new template in the Theme editor and select it here.
  2. In the Theme editor, open the collection (select it from the dropdown at the top) and click the Collection pages section.
  3. Click Add block and choose Single Card or Double Card.
  4. Set Position: the product space where the banner appears, for example 7.
  5. In Show for collections, enter the collection handle, for example collagen-products.
  6. Add the image (plus a mobile image for a Double Card), title, text, button text and link.
  7. Click Save.
Find the collection handle It's the last part of the collection's web address: /collections/collagen-products.

Hide a banner

  • In the Theme editor, click the eye icon on the block, or set Position to 0.

Check the image sizes

BannerDesktopMobile
Single Card900 × 1040px (portrait)Same image
Double Card1680 × 930px (landscape)1536 × 1700px (separate image)

The text is white, so use images that are dark enough to read it. Keep key details in the centre, because images crop to fill the space.

Good to know

  • The banner shows in the same position on every page of results.
  • If the position is higher than the number of products, the banner doesn't show.
  • Banners are the same in every market, unless you switch to a market in the Theme editor and edit them there.
